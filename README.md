# kankan-policy

칸칸 앱의 **개인정보처리방침**과 **이용약관**입니다.

- https://neheechulpublic.github.io/kankan-policy/privacy-policy
- https://neheechulpublic.github.io/kankan-policy/terms

앱 소스는 별도 비공개 저장소에 있습니다. 이 저장소는 스토어 등재에 필요한
공개 URL 을 내기 위한 것입니다. **원본은 앱 저장소의 `docs/` 이고, 고칠 때는
그쪽을 먼저 고친 뒤 여기로 복사합니다.**

두 문서 모두 앱이 실제로 하는 일에서 뽑았습니다. 코드가 바뀌면 함께 고쳐야
합니다.
